How to read this map ✨

  • Each dot is one memory. Dots near each other are about similar things.
  • Colour = which agent had the memory. Toggle agents on/off in the Profiles list below.
  • White-ringed dots = "shared topic". Multiple agents have memories about this — good candidates to make into shared knowledge (skills / world model).
What's under the hood
Trace summaries are embedded with BGE-large-en-v1.5 (1024-dim). UMAP projects them to 2D while keeping local structure: vectors close in 1024D stay close in 2D. HDBSCAN groups them into clusters; if a cluster touches ≥2 different profiles it's flagged "shared topic".
